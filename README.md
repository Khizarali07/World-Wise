# Worldwise (Course project)

A small world cities explorer built with Vite + React. The app demonstrates routing, context and reusable UI components while working with a cities dataset.

## Key features

- Browse cities and view details
- Search and filter by country/region
- Theme and small app-wide state via React Context

## Tech

- React + Vite
- CSS

## Run locally

1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`

## Notes

- Data lives in `data/cities.json`. You can extend it or connect a remote API for dynamic content.
